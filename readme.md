# projet NetMiko 
## une application de monitoring d'infrastructure reseau  

![interface](static/images/image.png)

# prerequis 

`python 3.14+`
`tailwindcss`
`django`

## Installation
intalle tout ce qui se trouve dans :

`requirements.txt`

avec le gestionnaire de paquet **pip**
`pip install requirements.txt`

apres avoir installer les equipements qui sont a l'interieurs 

# lancement de l'application
avec les commandes :
`python manage.py runserve`
le site sera disponible a l'adresse  `http://127.0.0.1:8000/`

** pour le moments, ce que nous avons mis c'est la landing page **
